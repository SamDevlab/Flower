# Flower 🌿💜

**Flores para minha flor** é um pequeno jardim digital feito como uma experiência romântica, leve e responsiva.

## Paleta

A identidade visual foi construída a partir da referência em tons de lavanda, verde e cinza:

- `#414B51` — Dead Forest
- `#5A6760` — Hockham Green
- `#777887` — Brewing Storm
- `#9492A4` — Alienator Grey
- `#BBB6C8` — Axis
- `#E2D7F1` — Pouty Purple

## Experiência

- Hero “Flores para minha flor” com buquê ilustrado em CSS
- Jardim interativo com seis flores e pequenos recados
- Carta especial em modal
- Botão para “colher” flores com animação de pétalas
- Layout responsivo para celular e desktop
- Respeito a `prefers-reduced-motion`
- Sem framework ou build: HTML, CSS e JavaScript puro

## Rodar localmente

Basta abrir `index.html` no navegador ou servir a pasta com qualquer servidor HTTP estático.

## Publicação

O projeto está pronto para ser hospedado como site estático, incluindo GitHub Pages.
